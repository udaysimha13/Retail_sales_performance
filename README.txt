 Retail Business Intelligence and Sales Forecasting Project

 Overview

This project analyzes retail sales data using Python, PostgreSQL, and Power BI. The objective is to identify business trends, evaluate profitability, and generate actionable insights through interactive dashboards and forecasting.

Tools Used

* Python
* Pandas
* Matplotlib
* PostgreSQL
* Power BI
* Prophet

 Key Features

* Data Cleaning and Preparation
* Exploratory Data Analysis (EDA)
* KPI Development
* Regional Performance Analysis
* Category and Sub-Category Analysis
* Profitability Analysis
* SQL Reporting and Queries
* Interactive Power BI Dashboard
* Sales Forecasting

 Business Insights

* West region generated the highest sales and profit.
* Technology category achieved the highest profitability.
* Phones and Copiers were top-performing sub-categories.
* Tables and Bookcases generated losses despite strong sales.
* Overall profit margin remained around 12.47%.
